## TypeScript

A collection of TypeScript code examples created while learning TypeScript fundamentals through tutorials and hands-on coding.

### About

This repository documents TypeScript , exploring its type system and the features it provides on top of JavaScript. The examples are organized by topic, progressing from basic syntax and configuration to more advanced type-system concepts.

### Topics Covered

- **Introduction and Setup** — TypeScript fundamentals, compiler setup, and project configuration
- **TSConfig** — configuring TypeScript compiler options
- **Debugging** — debugging TypeScript code during development
- **Built-in Types** — working with TypeScript's built-in types
- **Arrays and Functions** — typing arrays, function parameters, and return values
- **Objects** — defining and working with object types
- **Type Aliases** — creating reusable type definitions
- **Union Types** — allowing values to belong to multiple possible types
- **Intersection Types** — combining multiple types
- **Literal Types** — restricting values to specific literals
- **Nullable Types** — handling `null` and `undefined`
- **Optional Chaining** — safely accessing nested properties
- **Interfaces** — defining object structures and contracts
- **Type vs. Interface** — understanding the differences between the two
- **Classes** — object-oriented programming with TypeScript
- **Generics** — creating reusable, type-safe functions and structures
- **Type Narrowing** — refining types using conditions and type checks

### Getting Started

#### Prerequisites

- Node.js and npm
- Basic knowledge of JavaScript
- TypeScript compiler (`tsc`)

#### Clone the Repository

```bash
git clone https://github.com/naba93980/typescript.git
cd typescript
```

Install TypeScript if it isn't already available:

```bash
npm install -g typescript
```

Explore the topic folders and compile individual TypeScript files using:

```bash
tsc filename.ts
```

The generated JavaScript file can then be executed using Node.js.
